API 說明

← 回地圖首頁

本網站的前端不會直接呼叫 TDX，而是透過後端（server/index.js）代理， 統一處理 OAuth 授權與金鑰保護。以下是後端提供的公開端點，開發者可直接沿用， 或作為串接自己應用程式的參考。所有回應皆為 JSON，資料結構對應 TDX 「運輸資料流通服務平臺」Rail/Metro 系列 API。

基礎網址

{你的網站網址}/api

GET/api/status

回報伺服器是否已設定 TDX 金鑰（configured: true/false），前端據此決定顯示即時資料或示範資料。

{ "configured": true }

GET/api/stations

台北捷運車站基本資料，含站名、所屬路線、經緯度（TDX Metro/Station/TRTC）。

GET/api/lines

路線基本資料，含路線名稱與代表色（TDX Metro/Line/TRTC）。

GET/api/shapes

路線線型幾何座標，用於在地圖上繪出貼近真實軌道的路網（TDX Metro/Shape/TRTC）。

GET/api/liveboard

各站即時到站看板，含目的地與到站預估秒數（TDX Metro/LiveBoard/TRTC）。 本網站前端會用這份資料內插推算列車在地圖上的近似位置——這不是車輛的 實際 GPS 座標，因為北捷目前未對外公開精確列車定位。

使用範例

curl {你的網站網址}/api/liveboard

資料來源與授權

原始資料由 TDX 運輸資料流通服務平臺 提供，使用前請詳閱其資料授權條款。本網站僅作資料視覺化展示，不對資料的即時性、 準確性做保證。
